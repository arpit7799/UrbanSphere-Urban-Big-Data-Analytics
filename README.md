# CityPulse

## Urban Big Data Analytics

CityPulse is a Big Data Analytics project focused on discovering
relationships and patterns in Delhi's urban mobility, weather,
air-quality, and event data.

The project uses distributed data processing and analytics
technologies including Hadoop, HDFS, MapReduce, Apache Spark,
PySpark, and Spark SQL.

### Core Domains

- Urban Mobility
- Weather
- Air Quality
- Public Events
